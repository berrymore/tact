# Licensing

tact is open source hardware and software. Two licences apply, by directory:

| Paths | Licence | Text |
|---|---|---|
| `hw/`, `docs/` | CERN Open Hardware Licence Version 2 – Permissive (CERN-OHL-P-2.0) | [`LICENSES/CERN-OHL-P-2.0.txt`](LICENSES/CERN-OHL-P-2.0.txt) |
| `rtl/`, `fw/`, `emu/`, `sim/`, `tools/` and everything else | MIT | [`LICENSES/MIT.txt`](LICENSES/MIT.txt) |

Third-party components keep their own licences, recorded next to the imported code. Only
permissively licensed third-party code is accepted into this repository.
